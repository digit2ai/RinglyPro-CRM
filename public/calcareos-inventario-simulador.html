Sobre esta simulación. Este simulador reproduce el comportamiento del sistema propuesto con datos de demostración; no está conectado a producción, a Siigo, a World Office ni a los inventarios reales de Calcáreos S.A. La aritmética de área, la regla de retal/desperdicio y los contratos de API mostrados son los que se implementarían. Quedan explícitamente fuera de este alcance: optimización geométrica de nesting 2D, exportación PDF/Excel, migración histórica desde Excel, campos de reporte DIAN/IVA e interfaz de piso de planta para tableta.
Datos operativos, no personales — Ley 1581 de 2012 (Habeas Data). Este sistema no almacena datos personales.

Conecta una fuente de captura

Una clave, dos direcciones. Envía el trabajo observado con ingest; deja que tu propia IA lea la hoja de ruta con read.

1 · Crea una clave

Esta es la única vez que se muestra esta clave. Se guarda como hash y no se puede recuperar. Si la pierdes, revócala y crea otra: ese es el resultado correcto, no un problema.

2 · Instala el grabador

Extensión del navegador

Chrome, Edge o cualquier navegador basado en Chromium. Registra la forma del trabajo en el navegador: qué sistema, qué tipo de acción y cuánto tiempo. Mientras está activa, un aviso permanece visible en cada página: una herramienta de captura que nadie puede ver es software espía, sin importar lo que recopile.

  1. Descarga y descomprime la carpeta
  2. Abre chrome://extensions y activa el Modo de desarrollador
  3. Cargar descomprimida → elige la carpeta
  4. Haz clic en el ícono, pega tu clave ingest y presiona Conectar

Integraciones y tus propios sistemas

Cualquier cosa que pueda hacer una petición HTTP puede enviar una ejecución. Útil cuando el trabajo ocurre en una aplicación de escritorio que el navegador no ve, o cuando ya tienes un registro de eventos.

POST /discovery/api/v1/ingest/capture Authorization: Bearer synthex_dk_… { "label": "facturación de cierre de mes", "actor": "ops-2", "external_ref": "run-4471", "duration_ms": 1860000, "steps": [ {"action":"navigate","url":"https://acme.my.salesforce.com/orders/8837", "dwell_ms":42000}, {"action":"copy","host":"acme.my.salesforce.com","dwell_ms":3000}, {"action":"paste","native_app":"excel.exe","dwell_ms":9000} ] }

Volver a enviar el mismo external_ref no hace nada, así que un reintento después de un tiempo de espera agotado no puede contar horas dos veces en tu modelo de costos.

3 · Conecta tu IA a la hoja de ruta

Cualquier cliente MCP (Claude, un copiloto o tu propio agente) puede consultar la evaluación con una clave con permiso read.

{ "mcpServers": { "synthex-discovery": { "url": "https://synthexsai.com/discovery/mcp", "headers": { "Authorization": "Bearer synthex_dk_…" } } } }
La lectura no puede confirmar un proceso, fijar una tarifa por hora ni responder una pregunta de postura. Esos son los juicios humanos en los que se basa cada cifra: un agente que pudiera darlos podría fabricar una hoja de ruta de principio a fin sin nadie de por medio.

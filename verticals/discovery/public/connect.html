Connect a capture source

One key, two directions. Push observed work in with ingest; let your own AI read the roadmap back out with read.

1 · Mint a key

This is the only time this key is shown. It is stored as a hash and cannot be recovered. If you lose it, revoke it and mint another — that is the correct outcome, not a problem.

2 · Install the recorder

Browser extension

Chrome, Edge or any Chromium browser. Records the shape of browser work: which system, which kind of action, how long. A banner stays visible on every page while it runs — a capture tool nobody can see is spyware, regardless of what it collects.

  1. Download and unzip the folder
  2. Open chrome://extensions, turn on Developer mode
  3. Load unpacked → pick the folder
  4. Click the icon, paste your ingest key, press Connect

Integrations and your own systems

Anything that can make an HTTP request can push a run. Useful when the work happens in a desktop application the browser cannot see, or when you already have an event log.

POST /discovery/api/v1/ingest/capture Authorization: Bearer orbup_dk_… { "label": "month-end invoice run", "actor": "ops-2", "external_ref": "run-4471", "duration_ms": 1860000, "steps": [ {"action":"navigate","url":"https://acme.my.salesforce.com/orders/8837", "dwell_ms":42000}, {"action":"copy","host":"acme.my.salesforce.com","dwell_ms":3000}, {"action":"paste","native_app":"excel.exe","dwell_ms":9000} ] }

Re-pushing the same external_ref is a no-op, so a retry after a timeout cannot double-count hours into your cost model.

3 · Point your AI at the roadmap

Any MCP client — Claude, a copilot, your own agent — can query the assessment with a read-scoped key.

{ "mcpServers": { "orbup-discovery": { "url": "https://orbup.app/discovery/mcp", "headers": { "Authorization": "Bearer orbup_dk_…" } } } }
The read surface will not confirm a process, set an hourly rate, or answer a posture question. Those are the human judgements every figure rests on — an agent that could supply them could manufacture a roadmap end to end with nobody in the loop.

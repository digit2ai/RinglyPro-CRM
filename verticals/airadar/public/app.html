Get it onto your phone

The goal is a share sheet entry that behaves exactly like sending a post to yourself on WhatsApp: tap, saved, back to scrolling. Android and desktop Chrome use the built-in share target; iOS needs a one-time Shortcut because Safari does not implement Web Share Target.

Install first. On Android Chrome use the menu, then "Install app". On iPhone open this page in Safari, tap Share, then "Add to Home Screen".

Android / desktop Chrome

  1. Install AI Radar as an app (above).
  2. In Instagram, Facebook, TikTok or X, tap Share.
  3. Pick AI Radar. It is saved the moment you tap it — nothing to fill in.

iPhone — Shortcut (one action)

Copy the address below first, then build this. It is a single action: the shortcut hands the link to Safari, which does the saving. That avoids the network errors iOS throws when a shortcut tries to make its own request from inside a share sheet.

loading
  1. Shortcuts app → + → search Open URLs and add it.
  2. Tap the ⓘ in the bottom toolbar and turn on Show in Share Sheet. Close the panel.
  3. Tap the URL field in the action and paste the address above. It must end with &u=
  4. With the cursor still at the very end, tap Shortcut Input in the strip above the keyboard, so the field reads ...&u= followed by a blue chip.
  5. Rename it "Save to AI Radar" and go back to save.

Then: share any post, tap the shortcut, a "Saved" screen flashes up, and you are done. Anyone holding that address can add items to your radar, so treat it as a password. Rotating it breaks any shortcut using the old key.

iPhone — silent version (advanced)

If you would rather nothing opened at all, use Get Contents of URL pointed at /api/v1/capture?key=... with Method POST, Request Body JSON, and one text field url set to Shortcut Input. It saves without leaving the app, but iOS sometimes refuses to run it from a share sheet ("the network connection was lost"). The one-action version above is the reliable one.

Get it onto your phone

Two ways in. Android and desktop Chrome use the built-in share target; iOS needs a one-time Shortcut because Safari does not implement Web Share Target.

Install first. On Android Chrome use the menu, then "Install app". On iPhone open this page in Safari, tap Share, then "Add to Home Screen".

Android / desktop Chrome

  1. Install AI Radar as an app (above).
  2. In Instagram, Facebook, TikTok or X, tap Share.
  3. Pick AI Radar. The link arrives here with the draft already running.

iPhone — Shortcut (saves without opening anything)

  1. Open the Shortcuts app, create a new shortcut, and turn on Show in Share Sheet under its details. Set "Receive" to URLs.
  2. Add the action Get Contents of URL.
  3. URL: paste the address below.
  4. Set Method to POST, Request Body to JSON, and add one text field named url whose value is the Shortcut Input.
  5. Name it "Save to AI Radar". From then on, Share, then that shortcut, from any app.

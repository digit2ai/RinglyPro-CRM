# Move digit2ai.com email off Network Solutions

Status: PLANNED for 2026-11-02. Owner: Manuel Stagg.

## Why

Network Solutions' inbound filter (Vade / OX, `mx00X.netsol.xion.oxcs.net`) blocks and throttles
SendGrid's shared sending IPs. Measured in SendGrid on 2026-10-30 to 2026-11-01:

- 2 Supply password-reset codes to mstagg@digit2ai.com: `not_delivered` / deferred
  ("blocked by Validity", "IPs were throttled by recipient server").
- 2 meeting confirmations (Digit2AI, Synthex SAI) to mstagg@digit2ai.com: `not_delivered`.

This is the RECEIVING side. New sender addresses or subdomains do not fix it.

## What we found (2026-11-01)

| Item | Where |
|---|---|
| Domain registrar | Cloudflare (expires 2028-02-12). Not Network Solutions. |
| DNS | Cloudflare (`love` / `braden.ns.cloudflare.com`) |
| MX | 4 x `mx00[1-4].netsol.xion.oxcs.net` (Network Solutions) |
| SPF | `v=spf1 include:spf.cloudus.oxcs.net include:sendgrid.net ~all` |
| DMARC | `v=DMARC1; p=none;` |
| SendGrid domain auth | `em4316` valid (keep untouched) |
| Other Netsol records | `autodiscover` -> hostingplatform.com, `mail` -> netsolmail.net |
| Mailboxes | mstagg@digit2ai.com, info@digit2ai.com (check if info@ is a mailbox or an alias) |
| App dependency | Projects Hub unified inbox, `email_accounts` id 4: mstagg@ over IMAP `imap.digit2ai.com` |

So the move touches ONLY email: the website, the registrar and every other DNS record stay as they are.

## Target

Google Workspace, Business Starter (about $7-8 per user per month).

- 1 paid user: mstagg@digit2ai.com
- info@digit2ai.com as a free alias of mstagg@ (or a free Google Group if several people must read it).
  Only pay for a second user if info@ needs its own separate login.

Why Google: the Projects Hub already has a password-free Gmail connect (OAuth), and Google accepts
SendGrid mail far more reliably than Network Solutions.

## After that: system email strategy (separate task)

Sending addresses need no inbox; they only need to be authenticated in SendGrid.

- Appointments / reminders: `appointments@notify.digit2ai.com` (reply-to `info@digit2ai.com`).
- Password resets and sign-in codes: `no-reply@accounts.digit2ai.com`.
- Branded products send from their own domain (e.g. `citas@synthexsai.com`; Planea already uses `no-responder@planea.co`).
- One shared setting per kind of email (e.g. `MAIL_FROM_APPOINTMENTS`, `MAIL_FROM_AUTH`) read by every vertical.
- Each subdomain = about 3 CNAME records in Cloudflare, generated by SendGrid.

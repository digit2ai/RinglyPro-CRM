Build phases

Seven, and two of them are gates

Phases 3 and 4 hold gates the build cannot walk past. Phase 7 is what makes the next session cheaper than this one.

01

Analyze

Decompose into work units, map each to the agents that own it, right-size the fan-out.

02

Develop

Models, migrations, routes, services, UI, env-var docs. Deployable code, never pseudocode.

03

Test Gate · SIT

A green SIT with zero external keys is what done means here. Run the vertical's suite; write one if the vertical is new. Test the invariants, not the happy path.

04

Deploy Gate · review

Delegate to /code-review and /security-review before the push, not after. Then commit and push to main; Render deploys in ~90–100s.

05

Review

Poll health and the /debug/*-error endpoints. Verify each feature live, not locally.

06

Auto-fix

Loop back to Develop on any failure, capped at ~8 cycles per component. Past the budget it ships the rest and reports the blocked item — it never stops the whole build to ask.

07

Record Added

CLAUDE.md for anything structural, memory/ for what the code cannot show. If you spent real time working something out and the answer is invisible afterwards, it goes in one of the two.

House patterns

The five things this repo does its own way

Each one produces a bug that looks like something else entirely, ships green, and gets found in production. Copy the pattern; never invent a second way to do the same thing.

Migrations — alter:true is banned

sync({alter:false}) never adds a column to an existing table. The model boots clean, reads undefined forever, and nothing errors.

  • New columns go in the vertical's init as idempotent ADD COLUMN IF NOT EXISTS
  • Name every index explicitly — auto-names collide across re-runs
  • Schema operations are POST with an admin key. A wrong key answers 404, not 403

Custom domains — register near the top

Express matches in registration order, and the CRM defines hundreds of paths below. A late handler shadows only the paths the CRM happens to define — so the brand domain works until someone visits /admin.

  • An unowned path ends in that vertical's branded 404, never the CRM
  • Let /embed/, /api/voice-agent/ and /api/tts/ through untouched
  • Mount the shared TTS route inside the vertical when it owns a whole domain

PWA — never hardcode a mount prefix

A manifest's scope resolves against its own URL. Serve a /x/-scoped manifest on x.com and the install excludes the site's own root — tapping the logo drops the user into a browser tab.

  • One server-side generator keyed on req.baseUrl; no manifest on disk
  • Cache shell entries individually — addAll is atomic, one 404 leaves no worker
  • Never cache /api/

MCP tools — the gateway owns the tenant

  • tenant_id is injected from session and deleted from tool arguments
  • listTools computes trust exactly as callTool does, or gated tools leak into the listing
  • Keys are one-directional: an ingest key reads nothing back
  • Every call writes an audit row — including every denial

Honesty is enforced in code, not in the prompt

A model asked for a number returns a plausible one. A model asked to be honest agrees, and then is not.

  • The model writes prose. It never writes a named entity or a figure
  • Verify after generating, on every path — the deterministic one too
  • null over a guess. An unstated figure is omitted and named as absent
  • A short window is reported with its window, never multiplied into a rate
  • A machine's grouping is a proposal until a human confirms it
  • Label the keyless path; never fake it and never break it
  • Nothing auto-sends. Draft, a human approves, they send

Specialist briefs

Five blocks, every time

A specialist without these returns commentary instead of an artifact, and the work gets done twice. Nine written specs cover ten roles on top of this — Data Scientist and Statistician share one — marked full brief written on the bench above.

BlockWhat goes in it
RoleOne sentence of identity, and where in the pipeline they sit — who feeds them, who consumes them
DeliverableThe exact artifact and its shape, with file paths. "A migration plus the idempotent ALTER block", not "help with the database"
ContextThe specific files, the table prefix, the tenant model, the relevant invariants. Never "read the repo"
Success criteriaWhat makes it correct, stated so it can be checked — including the SIT assertion that will be written against it
ConstraintsMulti-tenant · bilingual · no emojis · Spanish orthography · null over a guess · the keyless path works · nothing auto-sends
Report what you could not do. A specialist that silently narrows its own scope is the most expensive failure in a fan-out, because the Brain integrates the gap without ever seeing it.

Cost & quote math

Deterministic, and done exactly this way

Hours stay identical between the two documents. cost is the source of truth and is generated first; quote is derived from it.

internalRate   = $70/hr          // default; override with "cost 45" or a pinned project rate
lineCost       = hours × internalRate
CAPEX_cost     = Σ lineCost
total_cost     = CAPEX_cost + OPEX_cost   // cost mode stops here. No profit. No IVA.

// quote mode only:
linePrice      = lineCost × 1.70      // +70% profit
subtotal_price = CAPEX_price + OPEX_price
IVA            = subtotal_price × ivaRate  // Colombia 19%, México & Venezuela 16%
total_quote    = subtotal_price + IVA
A PoC is scoped in weeks, four at most — never months. Every level must reconcile: components sum equals weekly sum equals CAPEX total. cost carries the red SOLO COSTO · NO DISTRIBUIR AL CLIENTE banner and never leaves Digit2AI.
